# Machine Learning (Aprendizaje Automático)

## ¿Qué es?

El **Machine Learning (ML)** es una rama de la IA donde los sistemas aprenden de los datos en lugar de ser programados explícitamente.

## Tipos de aprendizaje

1. **Aprendizaje supervisado**
   - Se entrena con datos etiquetados
   - Ej: clasificar correos como spam o no spam
   - Algoritmos: regresión lineal, árboles de decisión, redes neuronales

2. **Aprendizaje no supervisado**
   - Sin etiquetas, busca patrones ocultos
   - Ej: agrupar clientes por comportamiento
   - Algoritmos: k-means, clustering jerárquico

3. **Aprendizaje por refuerzo**
   - Un agente aprende por prueba y error
   - Recibe recompensas o penalizaciones
   - Ej: robots, juegos (AlphaGo)

## Flujo de trabajo básico

```
Datos → Preprocesamiento → Entrenamiento → Evaluación → Despliegue
```

## Conceptos importantes

- **Overfitting**: el modelo memoriza los datos de entrenamiento y falla con nuevos datos
- **Underfitting**: el modelo es demasiado simple para capturar el patrón
- **Feature engineering**: seleccionar y transformar las variables relevantes
- **Precisión vs Recall**: métricas clave para evaluar modelos de clasificación
