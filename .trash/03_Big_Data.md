# Big Data

## ¿Qué es el Big Data?

El **Big Data** se refiere a conjuntos de datos tan grandes o complejos que los métodos tradicionales de procesamiento no son suficientes.

## Las 5 V del Big Data

1. **Volume** - Cantidad masiva de datos (terabytes, petabytes)
2. **Velocity** - Velocidad de generación y procesamiento de datos (en tiempo real)
3. **Variety** - Diversidad de formatos (texto, imagen, video, sensores)
4. **Veracity** - Calidad y fiabilidad de los datos
5. **Value** - Valor obtenido al analizar los datos

## Tecnologías clave

### Almacenamiento y procesamiento
- **Hadoop** - Framework distribuido para procesamiento masivo
- **Spark** - Procesamiento en memoria, más rápido que Hadoop
- **HDFS** - Sistema de archivos distribuido de Hadoop

### Bases de datos
- **NoSQL**: MongoDB, Cassandra (datos no estructurados)
- **Data Warehouses**: BigQuery, Snowflake

### Flujos de datos
- **Kafka** - Streaming de datos en tiempo real
- **Flink** - Procesamiento de flujos

## Arquitectura básica

```
Fuentes de datos → Ingesta → Almacenamiento → Procesamiento → Análisis → Visualización
```

## Conceptos complementarios

- **Cloud Computing**: AWS, Google Cloud, Azure para escalar recursos
- **ETL** (Extract, Transform, Load): pipeline para preparar datos
- **Data Lake**: almacén crudo de datos en su forma original
- **Data Mesh**: enfoque descentralizado de gestión de datos
