# Virtual Environment

El virtual environment de Python ens serveix per poder deixar tancat el nostre programa de Python en un entorn virtual i això en protegeix de diferents atacs i perills i a més a més té altres avantatges.
- Les dependències s'instal·len al virtual env.
- Ens protegim que el programa toqui el nostre SO.
- En el nostre cas de programar IA ens protegim que pugui accedir al nostre sistema.
- No embrutim la instal·lació base de Python.
- El nostre programa el podem passar a altra màquina i funcionarà sense problema.

Per instal·lar llibreries ara entrarem a dins del virtual env i instal·la-les amb la comanda "pip install (nom de llibreria)".

Tambe si volem pasar a altre dispositiu podem fer "pip freeze > requirements.txt".
