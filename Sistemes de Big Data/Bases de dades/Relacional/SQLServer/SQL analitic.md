# SQL analitic
A SQL bàsic utilitzem les típiques sentències SQL bàsiques, però quan fem un tractament a nivell de grans quantitats de dades utilitzarem SQL analític que és molt avançat.

A SQLServer veurem "PIVOT" que amb aquest SQL generarem CUBS que són molt ràpids i comprimeixen la informació dins seu i quan requerim la informació ens la poden proporcionar molt ràpidament, de generació de CUBS hi ha de diferents.

El SQL analític l'utilitzarem a bases de dades OLAP que serà per consultes molt ràpides.
