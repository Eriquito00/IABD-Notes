# Cloud
Perquè si utilitzar el Cloud:
- Rapidesa
- Inversió inicial barata o nula
- Escalabilitat

Diferències entre despesa i inversió.

Despesa:
- Sous
- Claude
- Programari (pagament per ús mensual)

Invasió:
- Servidor
- Projecte en IA
- Programari (únic pagament)

D'acord amb el Cloud podem tenir:
- IaaS: comprem infraestructura (processador, emmagatzematge...)
- SaaS: comprem una eina (Gmail)
- PaaS: comprem un programari (Office 365)
